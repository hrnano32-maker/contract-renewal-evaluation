ระบบประเมินต่อสัญญาจ้าง · Firebase HR

กำลังตรวจสอบการเชื่อมต่อ...

ต้องตั้งค่า Firebase Project สำหรับ HR และกำหนดสิทธิ์ผู้ใช้ก่อนใช้งานจริง

1. ข้อมูลพนักงานและผู้ประเมิน

2. ประเมินผลการปฏิบัติงาน (10 หัวข้อ)

เลือกคะแนน 0–10 ในแต่ละหัวข้อ โดย 9–10 ดีเยี่ยม, 7–8 ดี, 5–6 ปานกลาง, 3–4 ต้องปรับปรุง, 0–2 ไม่ผ่านเกณฑ์

คะแนนรวม 0 / 100 คะแนน — ยังประเมินไม่ครบ

3. การมาปฏิบัติงานระหว่างอายุสัญญา

รวมจำนวนวันที่หยุด/ลา: 0 วัน

4. เหตุผลประกอบการพิจารณา

5. ผลการพิจารณาและการอนุมัติ

สถานะ: ฉบับร่าง

ต้นแบบนี้บันทึกข้อมูลในเบราว์เซอร์เครื่องที่ใช้งาน การอนุมัติเป็นการจำลองเท่านั้น ยังไม่มีระบบล็อกอิน สิทธิ์อนุมัติ ลายเซ็นดิจิทัล หรือฐานข้อมูลกลาง

ผลประเมินพนักงานจากทุกแผนก

แสดงข้อมูลที่หัวหน้าส่งพิจารณาแล้วโดยอัตโนมัติ และให้ HR อนุมัติหรือส่งกลับแก้ไข

พนักงานแผนกผู้ประเมินคะแนนสถานะดำเนินการ
